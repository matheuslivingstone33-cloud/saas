# Assets (placeholders)

Arte provisoria. Trocar pela identidade de marca definitiva sem mexer em codigo:
mantenha os mesmos nomes de arquivo.

| Arquivo | Uso | Substituir por |
|---|---|---|
| `favicon.svg` | icone da aba | favicon definitivo (SVG ou ICO 32x32) |
| `logo.svg` | cabecalho do app | logotipo horizontal |

Formatos sugeridos: SVG para logo e favicon; PNG @2x para imagens de marketing.
